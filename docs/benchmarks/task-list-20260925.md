# Task list latency benchmark

- Date: 2026-09-25 13:10 UTC
- Machine: Linux-7.0.0-31-generic-x86_64-with-glibc2.43, Python 3.12.14
- Database: PostgreSQL 16 in Docker on the same machine (docker compose, default settings)
- Data: 100,000 tasks in one project · each sample = first page + second page (limit 50, sort -created_at)
- Runs: 200 samples per variant after warm-up
- Command: `uv run python scripts/bench_tasks.py --rows 100000 --runs 200`

| Variant | Latency |
|---|---|
| With `(project_id, created_at, id)` index | p50 1.78 ms · p95 2.41 ms · mean 1.92 ms |
| Without it (and without `(project_id, status)`) | p50 26.92 ms · p95 34.81 ms · mean 27.84 ms |

Measured on a developer laptop, not production hardware. Use it for the *relative* difference.
